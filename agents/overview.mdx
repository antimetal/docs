## Install in one step

<CodeGroup>

```bash Claude Code plugin
/plugin marketplace add antimetal/skills
/plugin install antimetal
```

```bash Any MCP client
npx -y add-mcp "https://mcp.antimetal.com/?src=add-mcp"
```

```bash Claude Code (server only)
claude mcp add --transport http antimetal "https://mcp.antimetal.com/?src=docs-claude-code"
```

</CodeGroup>

Or hand the setup to your agent:

```text
Read https://docs.antimetal.com/agents/get-started.md and follow it to set up Antimetal.
```

## Docs your agent can read

Every page on this site is also plain Markdown, so agents read it without parsing HTML.

| Resource | URL | Use it for |
| --- | --- | --- |
| Markdown pages | Add `.md` to any URL, such as [`/agents/mcp.md`](https://docs.antimetal.com/agents/mcp.md) | Give an agent one page. |
| Page index | [`/llms.txt`](https://docs.antimetal.com/llms.txt) | Let an agent find the right page. |
| Full docs | [`/llms-full.txt`](https://docs.antimetal.com/llms-full.txt) | Load every page in one file. |
| Docs MCP server | `https://docs.antimetal.com/mcp` | Let an agent search these docs as a tool. |

Each page also has a menu at the top to **Copy page** as Markdown, or open it in ChatGPT, Claude, Cursor or VS Code.

## What agents do with Antimetal

- **Investigate.** "Why is checkout slow?" The agent asks Antimetal, reads the Issue's root cause and evidence, and explains it.
- **Fix.** "Apply the fix for issue 412." The agent pulls the diff, adapts it to your code, opens a pull request and links it back to the Issue.
- **Prevent.** "Run a database health check before the launch." The agent runs a [Patrol](/product/patrols) and works through what it finds.
- **Teach.** "Tell Antimetal to ignore the legacy billing service." The agent steers the Patrol or adds a rule, so the next run is better.
